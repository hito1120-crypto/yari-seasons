# 槍ヶ岳 川と雪の一年(2017–18)

槍ヶ岳周辺(約15km四方)の「川の増水」「積雪」「冬山の環境学習」を3Dで見る学習用ページです。**模式表現**であり、実水位・流量・積雪の実測ではありません。

- ページ: `index.html`(単一HTML、PC・スマホ対応)
- 動画: `yari-seasons.mp4`(32秒)
- 降水・積雪はERA5-Land(再解析、約9km格子)です。約9km格子のため、局地的な大雨は弱く出ます。
- 冬山は計画の根拠にしないでください。専門家の同行と登山届が必要です。経路・所要時間は表示しません。

## 出典・ライセンス
- 地形・県境: 国土地理院「地理院タイル」(標高タイル DEM10B、ベクトルタイル)を加工して作成(ベクトルタイルの条件は要確認)
- 山名・山小屋・川名・位置: © OpenStreetMap contributors (ODbL)
- 降水・積雪: ERA5-Land(Copernicus Climate Change Service)を加工。降水は total_precipitation(時間値)、積雪は snow_depth を標高配分した推定。Muñoz Sabater (2019), DOI 10.24381/cds.e2161bac。CC-BY(最終確認は要確認)
- 雪崩の傾斜: 国土交通省砂防部保全課「雪崩とは」(2006年1月17日)
- 3D描画: three.js (MIT)
